## Recommended execution order

1. **006** first — it touches the `ease` literal in `Header.tsx`, `ScrollReveal.tsx`, `TestimonialScrollCard.tsx`, `LaserPhysicsDiagram.tsx`, and `WaveDivider.tsx`. Running it first avoids a second agent editing the same import lines those files will need for plan 001.
2. **001** next — depends on 006 only in the sense that it touches the same files (`ScrollReveal.tsx`, `LaserPhysicsDiagram.tsx`); if 006 already ran, `ScrollReveal.tsx`'s `ease` value will appear as `EASE_OUT_EXPO` (imported from `lib/motion.ts`) instead of the literal `[0.16, 1, 0.3, 1]` — plan 001's diff only adds `useReducedMotion` branching around the existing `ease` value and doesn't need to change which form it's in.
3. **002, 004, 005** — independent of each other and of 001/006, touch different components (`MobileNav.tsx`, and two separate blocks within `LaserPhysicsDiagram.tsx`). 004 and 005 both edit `LaserPhysicsDiagram.tsx` but in non-overlapping line ranges (the hotspot pulse vs. the tooltip) — safe to run in either order, just not truly in parallel by two agents editing the same file simultaneously.
4. **003, 007, 008** — fully independent, any order, can run any time (before or after the above).
